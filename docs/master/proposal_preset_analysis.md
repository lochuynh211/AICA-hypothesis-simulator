## How to read this

A content **fit** is a signed weighted average of ~15 features that sum to 1, so it lives in a narrow band by construction: a cold-start driver tops out near **0.10–0.20** (much of the weight — oshi / age / play / recovery history — has nothing to act on, and by design that missing weight is never redistributed), while a driver with an in-catalog oshi + real history legitimately reaches **0.37–0.44**. Low is not broken — it is an honest cold start.

Drowsiness/fatigue/monotony in each brief are grounded in the trigger-mode driver-signal model, so the journeys track a physically plausible arc: drowsiness outpaces fatigue, a real break (sleep/karaoke/stretch) knocks it back down, and the proposal shifts from **energize** (fight the boredom) to **soothe** (wind down) accordingly.
