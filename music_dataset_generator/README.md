This package is the offline, Soundcharts-grounded music dataset generator for the AICA Hypothesis Simulator. It produces the frozen song catalog and test cases used by proposal P2. The deterministic core (planning, transformation, certification) requires no network access or LLM calls; only the `harvest` and `resolve` subcommands contact external APIs. See `specs/012-music-dataset-generator/` for the full specification and design docs.
